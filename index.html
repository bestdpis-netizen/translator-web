엔진 설정

이 번역기는 API 키나 로그인 없이 동작합니다. 두 가지 무료 엔진을 사용합니다.

① 브라우저 내장 번역기 (권장)

Chrome / Edge 138 이상 데스크톱에 내장된 기기 내(on-device) 번역 엔진입니다. 처음 쓰는 언어쌍은 언어팩을 한 번 내려받고(수십 MB), 그 뒤로는 인터넷 없이·분량 제한 없이 번역됩니다. 원문이 외부로 전송되지 않아 대외비 문서에 적합합니다.
